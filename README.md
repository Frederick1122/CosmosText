# CosmoTextGame

Текстовая survival-RPG для телефона в космическом сеттинге. Герой — пассажир грузового корабля «Персефона», летевший в криосне к колонии Мейер-4. После аварийного пробуждения он приходит в себя в капсуле гибернации на обломке корабля, память возвращается урывками и выживает, следя за HP, кислородом, силами, голодом и патронами. Он принимает решения в текстовых ситуациях (с пиксельными иллюстрациями), ходит по узловой карте палуб и сражается в пошаговом бою с дистанцией и манёврами в духе Neo Scavenger. Дни сменяются сном на базе. Смерть необратима (permadeath), но лор-архив её переживает, а откат к чекпойнту доступен за рекламу или по полному доступу.

**Статус:** играбельный срез с замкнутым циклом. Два сектора — `wreck_01` («Персефона», 3 палубы) и `wreck_02` (ретранслятор «Вехтер-9», 2 яруса): 12 модулей-локаций с 52 событиями, 17 ситуаций, 22 предмета, 5 навыков, 3 рецепта, 3 врага, 7 лор-фрагментов, 9 статей справочника, 5 целей и 2 финала. Забег проходит от пробуждения в отсеке гибернации до спасения или смерти: две базы, дни, силы и голод, уровни и опыт, поэтапное исследование модулей, крафт, журнал со справочником мира, узловая карта с туманом и лифтами, бой с манёврами, перелёт между секторами и автосохранения.

Дизайн-документы (`gdd-v1.md`, `tech-spec-v1.md`) лежат в Claude-проекте «CosmoTextGame», а не в этом репозитории. Ссылки вида «ТЗ раздел N» в комментариях кода ведут туда.

## Быстрый старт

1. Установить **Godot 4.7** (проект собран под 4.7.2, `config/features` в `project.godot` = `"4.7"`).
2. Godot → Import → выбрать `project.godot` в этой папке → Import & Edit.
3. **F5**: запускается `scenes/Game.tscn` (главное меню → вступление в отсеке гибернации → карта → модули и их события → бой → экран смерти).

Проверка контента после любой правки в `data/`:

```bash
python tools/validate_content.py
```

## Структура

```
project.godot              конфиг движка: автозагрузки, portrait 1080x1920, Mobile-рендерер
autoload/                  игровые системы-синглтоны (см. docs/ARCHITECTURE.md)
data/                      весь контент, отдельно от кода (см. docs/CONTENT.md)
  config.json              стартовые параметры забега, цены кислорода, силы и голод, награды опытом и уровни
  items.json               справочник предметов (слоты снаряжения, характеристики, взаимодействия)
  skills.json              навыки и бонусы за уровень
  recipes.json             рецепты крафта
  enemies.json             справочник врагов: ИИ, атака, трофеи, опыт, спецдействия
  lore.json                лор-фрагменты для Архива
  codex.json               справочник мира: места, люди, корабли и термины
  quests.json              журнал целей: мысли героя, цели и шаги
  explore_pools.json       пулы случайных событий исследования модулей
  endings.json             тексты финалов забега (эффект end_run)
  locations/*.json         модули: описание + события (авто/ручные, разовые/повторяемые, скрытые до исследования)
  situations/*.json        ситуации с выбором, которые запускают события
  sectors/*.json           узловые карты секторов (палубы, лифты, узлы)
scenes/
  Game.tscn / Game.gd      единственная игровая сцена, UI строится из кода
  ui/SectorMapView.gd      карта сектора: отсеки по статусам, фишка игрока, маршрут, камера, палубы
  ui/MarqueeLabel.gd       подпись с бегущей строкой
  ui/CharacterPanel.gd     экран персонажа: предметы, снаряжение, навыки, крафт
  ui/CharacterDollView.gd  схематичный персонаж со слотами снаряжения
  ui/UiKit.gd              общие UI-хелперы, в том числе загрузка пиксель-арта
  ui/CombatView.gd         экран боя: журнал схватки, карточки сторон, дистанция, манёвры у нижнего края, экран победы
  ui/XpBar.gd              полоса уровня и опыта в HUD и на экране победы
  Main.tscn / Main.gd      смоук-тест логики без UI (SMOKE OK / FAIL)
assets/art/scenes/*.png    иллюстрации сцен 160x96 (поле image в контенте)
assets/art/items/*.png     иконки предметов 16x16 (по id предмета)
assets/art/enemies/*.png   портреты врагов 64x64 для экрана боя (по id врага)
assets/art/portraits/*.png портрет игрока 64x64
tools/validate_content.py  офлайн-валидатор перекрёстных ссылок в JSON-контенте
tools/make_pixel_art.py    генератор пиксель-арта (чистый Python, без зависимостей)
addons/mcp_bridge/         плагин редактора: TCP-мост для Claude Code (порт 9500)
mcp_bridge_game.gd         автозагрузка: TCP-мост в запущенной игре (порт 9501)
mcp/                       Python MCP-сервер, связывающий Claude Code с Godot
```
